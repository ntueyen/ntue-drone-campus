# 北教大校園飛行練習原型

無人機入門飛行練習。從操場飛往泳健館、體育館或學生活動中心入口，點選進入後可在簡化的 3D 館內飛行或返回戶外；泳健館與體育館也可觀看 360 度實景。

左搖桿控制升降及機身旋轉；右搖桿控制前進、後退與左右平移。可切換第一人稱及第三人稱視角。

桌機鍵盤：W／S 升降、A／D 旋轉，方向鍵上／下前後飛行、左／右平移。外接手把預設為美國手：左桿升降與旋轉，右桿前後與平移。連接後按手把按鈕，開啟操作說明中的「外接手把設定」並勾選啟用；可依即時軸數值調整四個軸與反轉方向。開始或切換場景後，四軸需先移至中間才會生效。標準遊戲手把的 A 鍵可開始或進入館舍，B 鍵可返回戶外或關閉實景。瀏覽器與控制器的支援程度可能不同，非所有遙控器都能被瀏覽器辨識。

本作品為可行性原型，操場、體育館、泳健館外觀及泳池室內配置參考原作者提供的 360 照片；部分立面與地面採用照片裁切後的材質，其餘結構為近似模型。距離、飛行高度與速度為模擬數值，並非實際測量或真實無人機的飛行物理。校園空間相對位置參考 [國立臺北教育大學校園地圖](https://www.ntue.edu.tw/p/412-1000-2348.php?Lang=zh-tw)。照片原檔未公開。

體育館的室內木質球場、看臺及屋頂參考原始 360 照片建立簡化飛行場景；實景照片可於館內另行觀看，並非可自由移動的立體重建。

學生活動中心大廳參考校園導覽入口可見的圓柱、紅磚色帶、玻璃與樓梯製作為概念示意空間；內部深處的配置與尺寸未經實測或實景確認，柱子設有碰撞限制，不等同真實館內構造。

操場周邊參考校園導覽及原始照片，重製創意館、大禮堂、圖書館、視聽館、學生活動中心、篤行樓，並以簡化模型加入科學館與行政大樓。依校方地圖調整球場、視聽館與科學館、圖書館與行政大樓及活動中心的相對位置，小地圖北方及戶外航向對齊。圖書館與篤行樓入口使用原始照片裁切；其餘立面以幾何與材質示意，樓層、立面與距離未經實測，不能作為精確地圖。
