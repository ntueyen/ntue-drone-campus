# 北教大校園飛行練習原型

以平板橫向觸控操作為主的無人機入門飛行練習。從操場起飛，利用雙搖桿飛往泳健館附近，點選「進入泳健館飛行練習」即可繼續在簡化的 3D 館內飛行；館內亦可選擇觀看泳池 360 度實景或返回戶外。

左搖桿控制升降及機身旋轉；右搖桿控制前進、後退與左右平移。可切換第一人稱及第三人稱視角。

本作品為可行性原型，3D 建築及泳池室內配置依照片簡化呈現；距離、飛行高度與速度為模擬數值，並非實際測量或真實無人機的飛行物理。校園空間相對位置參考 [國立臺北教育大學校園地圖](https://www.ntue.edu.tw/p/412-1000-2348.php?Lang=zh-tw)。泳健館照片由原作者提供，原檔未公開。
